# Screenshots

Drop the app screenshots here with these exact filenames (PNG). The main
[README](../../README.md) references them. Suggested width ~700–900px.

| File | What to capture |
|------|-----------------|
| `popover.png`       | The tray popover — today / week / month totals with your avatar in the header. |
| `task-list.png`     | The main window — tasks & bugs with status pills, timers, per-task hours, and the log row. |
| `meeting-prompt.png`| The end-of-meeting dialog (Daily / Defined list / Search / Cancel) and/or the task picker. |
| `settings.png`      | The Settings window — Account or Meetings tab. |

Tip (macOS): `⌘⇧4` then space, click a window for a clean shot with shadow.
Crop out any sensitive task names/ids before committing if needed.
